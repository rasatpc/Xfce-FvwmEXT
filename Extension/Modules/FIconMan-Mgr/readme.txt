# readme.txt

FvwmIconMan without embedding (Swallow) it in FvwmButtons. FvwmIconMan keeps the config lightweight, consistent, and free of extra modules.

To install or edit:

## Add the line below:
Read $[EXT_DIR]/Modules/FIconMan-Mgr/IconMan-4mgr.sys

## For editing and modification, copy it to .fvwm/User and add the line in .fvwm/userEXT.sys
Read $[USER_DIR]/FIconMan-Mgr/IconMan-4mgr.sys
