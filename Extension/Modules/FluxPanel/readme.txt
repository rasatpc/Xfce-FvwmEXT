readme.txt

This is an optional extension that adds additional Fvwm features. It requires moving the Xfce panel to the left side, vertically.

To install in .fvwm/userEXT.sys

## Add the below line.
Read $[EXT_DIR]/Modules/FluxPanel/fluxbox-panel.sys

To edit

## Copy to .fvwm/User and add below line in .fvwm/userEXT.sys
Read $[USER_DIR]/FluxPanel/fluxbox-panel.sys
