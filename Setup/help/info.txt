FVWM is a Virtual Window Manager. What sets it apart from other WMs is that it is also a virtual window manager; it allows you to place windows on an area much larger than the visible display.

Other great features include window resizing, moving, and iconifying. FvwmRearrange is designed to clean up crowded layouts by automatically snapping windows into non-overlapping grids. Fvwm-OverView uses iconified, live thumbnails to help you visually pick a window out of a crowd.

FvwmEXT is a small set of configurations added to the default FVWM. When running inside a full desktop environment, it replaces the window manager component. It swaps out only the window management layer; the rest of the desktop environment, such as the panels, docks, desktop icons, and background wallpaper, will remain running.

Xfce-FvwmEXT (Extensions) (ver. 3.0.1)

It is a collection of ready-made configs, a model for you to use, modify, or create your own extensions. Includes three directories.

Extension - Functions, Decorators, Menus and Modules.
Setup - Additional configurations and scripts that setup the system at first run.
User - Reads user configs and makes changes to the .fvwm/Extension configs and settings.
