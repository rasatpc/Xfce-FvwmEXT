# Xfce with FvwmEXT

This model is designed to integrate Fvwm with Desktop Environments, enabling selected Fvwm configs to run on a DE and make it a perfect system. For example, Xfce is a exellant application manager, whereas Fvwm is one of the best window and virtual manager. This combination is lightweight yet offers unlimited functionality.

FvwmEXT adds new features to your Desktop Environment without interfering with the current system and setup.

It runs on DEs and WMs compliant with ICCCM 2.0. For example DE: GNOME, KDE, XFCE, LXQt, MATE. WM: Fluxbox, IceWM, Openbox.

At first Fvwm startup, it adds Fvwm2-3.desktop with the command "fvwm --replace" to .config/autostart/. It starts Fvwm when the DE starts.

The Fvwm configs (functions, decor, and modules) can be edited or created by you.
