# Xfce with FvwmEXT

This model is designed to integrate Fvwm with Desktop Environments, enabling selected Fvwm configs to run on a DE and make it a perfect system. For example, Xfce is a exellant application manager, whereas Fvwm is one of the best window and virtual manager. This combination is lightweight yet offers unlimited functionality.

It runs on DEs and WMs compliant with ICCCM 2.0. For example DE: GNOME, KDE, XFCE, LXQt, MATE and WM: Fluxbox, IceWM, Openbox.

For this model, FvwmEXT is minimized to include the most helpful configs to the Desktop Environment without interfering with the current system and setup.

# Main features:
* Iconified Thumbnails, Full-Screen Maximize, Fvwm Overview (over view of active windows), and Tiling (automatically snaps windows into non-overlapping grids).

* Pager 1x4 - miniature view of the desktops and pages.
* 4-button Window Title Bar - Tile, Iconify, Min and Max.
* Page Indicator - shows the active desk and page number.
* Auto Move Windows - automatically move apps to a specific desk/page.

Tested on Fvwm3 and Fvwm2

At first Fvwm startup, it adds Fvwm2-3.desktop with the command "fvwm --replace" to .config/autostart/. It loads Fvwm when the DE starts.
